ILIGAN CITY FIRE STATION SYSTEM - FIXED BUILD
================================================

1. Keep all files in this folder together.
2. Run main.py, or double-click run.bat.
3. The program uses text files only. No SQLite database is used.
4. data\ is created automatically on first run.
5. reports\ is created automatically when a report is saved.
6. The Reports page now saves generated reports as .txt files.
7. Settings now include Dark/Light appearance, auto refresh,
   refresh interval, and save notifications.

Important:
- Keep background.png, fire_logo.png, smc_logo.png and bell.wav
  beside main.py, frontend.py and backend.py.
- If CustomTkinter/Pillow are missing, install the packages listed
  in requirements.txt.
